# CompanyOS Battle Plan: AI-Powered Stock Portfolio Tool

- **Domain:** Finance / Fintech (Stock Portfolio, Technical Indicators, Sentiment Analysis).
- **Task Type:** Product (Build from scratch).
- **Force Level:** Full SDLC, `pro` and `inherit` models.
- **Roles to Deploy:**
  - `@MarketResearcher`
  - `@ArchitectDB`
  - `@BackendEngineer`
  - `@FrontendEngineer`
  - `@CybersecRedBlue`
  - `@QATester`
  - `@TechnicalWriter`
- **Phase Sequence:**
  - Phase 1: Requirements & Market Research
  - Phase 2: Architecture & System Design
  - Phase 3: Parallel Engineering (Backend, Frontend)
  - Phase 4: Security Hardening (Red/Blue Team)
  - Phase 5: QA & Validation Loop
  - Phase 6: Documentation & Delivery

- **Directory Structure:**
  - `docs/`: CompanyOS artifact sandbox
  - `src/backend/`: Backend engineer sandbox (Python/FastAPI)
  - `src/frontend/`: Frontend engineer sandbox (Vite/React)
  - `tests/`: QATester sandbox
  - `scripts/`: Validation scripts

- **Multi-Company:** No (Single Domain product).
